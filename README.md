# Aniq ur Rahman - Portfolio

A premium, high-performance personal portfolio website for Aniq ur Rahman, a Director of IoT & Infrastructure. This site showcases his expertise in Cloud Architecture, Digital Twins, and Product Strategy through a minimalist, Apple-inspired design.

## 🚀 Features

- **Premium Design**: Minimalist aesthetic with high contrast, smooth animations, and a refined color palette.
- **Interactive Elements**:
  - Dynamic "Story" section with scroll-triggered animations.
  - Interactive project case studies.
  - WebGL-inspired background effects.
- **Dark Mode**: Fully supported dark mode with smooth transitions.
- **Responsive**: Optimized for all devices, from mobile to large desktop screens.
- **Performance**: Built with Vite for lightning-fast loading and HMR.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) (v18)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🏃‍♂️ Getting Started

1.  **Clone the repository**
    ```bash
    git clone <repository-url>
    cd portfolio
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
